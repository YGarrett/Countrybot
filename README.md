# 🌍 CountryBot: Agente Historiador e Investigador Cultural

**CountryBot** es un agente de Inteligencia Artificial capaz de realizar investigaciones históricas y culturales profundas de cualquier país del mundo. Utiliza **LangChain** para orquestar el flujo, **Gemini** como motor de pensamiento, y herramientas como **Wikipedia** y **Tavily Search** para recopilar datos históricos y geopolíticos en tiempo real.

## 🚀 Características
CountryBot genera reportes estructurados que incluyen:
* Resumen histórico y cultural.
* Procesos de independencia y eventos fundacionales.
* Guerras civiles y conflictos internos clave.
* Participación en conflictos internacionales (Guerras Mundiales, etc.).
* Significado de la bandera y sus símbolos.
* Paradigma y situación geopolítica actual.
